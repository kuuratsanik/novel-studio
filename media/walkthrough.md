# Novel Studio

1. **Novel Studio: New Novel Workspace** — creates drafts/, codex/, contracts, prompts.
2. Fill drafts/contracts/ch01.json (goal, conflict, turn, exit).
3. Open drafts/ch01.md and run **Continue Scene** (Ctrl+Alt+N).
4. Accept or skip state patches into codex/state.json.
5. **Audit Continuity** (Ctrl+Alt+A).
6. Keys stay in SecretStorage. Enable novelStudio.privacyLocalCodex to keep bible off the cloud.
